# 용어 정의 사전 테스트 가이드

대상 기능: 속성패널(Process 탭)의 "용어 정의" 섹션, 통합 용어 사전 페이지(`/glossary`), 용어 재사용
관련 매뉴얼: `glossary-manual.md`

## 준비

- [ ] PAL 모드 테넌트, 프로세스 편집 권한(editor 이상) 계정으로 로그인
- [ ] 편집 가능한 프로세스 2개 준비 (예: `내부심사 프로세스`, `시정조치 프로세스`)
- [ ] DB에 `glossary_terms` 테이블 존재 확인 (마이그레이션 `20260915000002_glossary_terms.sql`)

## TC-1. 섹션 노출

| 단계 | 기대 결과 |
|---|---|
| 프로세스 열기 → 속성패널 Process 탭 | "용어 정의" 섹션 표시 (기본 위치: 관련자료 링크 다음) |
| 속성 스키마 스튜디오 목록 확인 | '용어 정의'(process 스코프, glossary) 행 존재 (첫 진입 시 자동 생성) |
| 스튜디오에서 해당 행 노출 해제 / 순서 변경 | 패널 섹션이 사라짐 / 위치 이동 (미리보기도 동일) |
| 읽기 전용 모드 진입 | 용어 목록만 보이고 추가·수정·삭제 UI 미표시 |

## TC-2. 용어 등록 (내부심사 프로세스)

| 단계 | 기대 결과 |
|---|---|
| 용어 `내부심사`, 정의 입력 후 추가 | 목록에 행 추가 + "용어를 추가했습니다" 알림 (즉시 저장) |
| 용어 `FA(Focus Area)` 추가 | 목록 2건 |
| 같은 용어 `내부심사` 다시 추가 시도 | "이미 이 프로세스에 등록된 용어입니다" 경고, 추가 안 됨 |
| 연필 아이콘 → 정의 수정 → 저장 | 수정 반영 |
| 페이지 새로고침 후 재진입 | 등록한 용어·정의 유지 |

## TC-3. 용어 추천·재사용

| 단계 | 기대 결과 |
|---|---|
| (내부심사 프로세스) 용어 입력란 클릭 (입력 전) | "기존 용어 추천" 목록에 등록된 용어 전체 표시 — 이 프로세스에 이미 있는 `내부심사` 등은 "이 프로세스에 등록됨" 표기와 흐린 스타일 |
| "이 프로세스에 등록됨" 항목 클릭 | 채워지지 않고 "이미 이 프로세스에 등록된 용어입니다" 경고 |
| 시정조치 프로세스 열기 → 용어 입력란 클릭 | 추천 목록에 `내부심사`, `FA(Focus Area)` 표시 (정의 미리보기 + 출처 프로세스명 포함, 등록됨 표기 없음) |
| `내부` 입력 | 목록이 `내부`가 포함된 용어로 좁혀짐 (일치 정확도 순) |
| 추천에서 `내부심사` 클릭 | 용어·정의가 자동으로 채워지고 "기존 용어의 정의를 불러왔습니다 (P5.4.3 내부심사 프로세스)" 안내 표시 |
| 정의를 일부 수정 후 추가 | 이 프로세스에는 수정된 정의로 저장, 원본 프로세스의 정의는 그대로 |
| 추천 없이 `FA(Focus Area)`를 직접 타이핑, 정의 비운 채 추가 | 기존 정의가 자동으로 채워져 저장됨 |
| 두 프로세스 모두에서 `내부심사` 용어 옆 칩 확인 | 사용처 수 2 표시 |
| 용어가 9개 이상일 때 입력 전 목록 확인 | 8개 표시 + "외 N개 — 계속 입력해 좁혀보세요" 안내 |

## TC-4. 통합 용어 사전 페이지

| 단계 | 기대 결과 |
|---|---|
| 사이드바 → 용어 사전 클릭 | `/glossary` 진입, 표준 페이지 구조(제목 "용어 사전" + 부제 + 새로고침 버튼) |
| 목록 확인 | `FA(Focus Area)`, `내부심사` 용어 카드 표시 (용어순), `내부심사`에 "2개 프로세스" 칩 |
| `내부심사` 카드 펼침 | 내부심사/시정조치 프로세스 각각의 정의가 나열됨 |
| 프로세스명 클릭 | 해당 프로세스의 체계도 화면으로 이동 |
| 검색창에 정의 본문 일부 입력 | 매칭 용어만 남음 · 용어/정의 건수 카운트 갱신 |
| 검색창에 프로세스명 입력 | 해당 프로세스에서 정의한 용어들만 남음 |

## TC-5. 대소문자·공백 동치

| 단계 | 기대 결과 |
|---|---|
| 한 프로세스에 ` fa(focus area) ` 로 추가 시도 (다른 프로세스에 `FA(Focus Area)` 존재) | 자동완성/재사용은 같은 용어로 취급, 통합 사전에서 한 용어로 묶임 |
