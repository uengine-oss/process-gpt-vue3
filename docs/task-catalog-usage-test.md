# Task Catalog — 순서도에서 사용하기 테스트 가이드

대상 기능: 변경(replace) 메뉴의 Task Catalog 그룹, 속성패널 Task 카탈로그 섹션의 불러오기/적용
관련 매뉴얼: `task-catalog-usage-manual.md`

## 준비

- [ ] PAL 모드 테넌트, 프로세스 편집 권한 계정으로 로그인
- [ ] 카탈로그에 테스트 항목 2개 등록 (`task-catalog-direct-registration-test.md` 절차 활용):
  - `결재 요청` — 유형 `사용자 작업`, RACI(R 조직 1개), 세부 절차 2단계, 사용자 정의 속성 값 1개
  - `데이터 백업` — 유형 `서비스 작업`, 설명 입력
- [ ] 편집 가능한 프로세스의 순서도 편집 화면 진입

## TC-1. 변경 메뉴 노출

| 단계 | 기대 결과 |
|---|---|
| 팔레트로 일반 작업(Task) 1개 배치 → 선택 → 스패너(변경) 아이콘 클릭 | 변경 메뉴 하단에 "Task Catalog" 그룹, `결재 요청`·`데이터 백업` 표시 |
| 각 항목의 아이콘 확인 | 카탈로그 Task 유형의 BPMN 아이콘 (사용자 작업/서비스 작업) |
| 메뉴 검색창에 `결재` 입력 | `결재 요청`만 남음 |
| 시작 이벤트 선택 → 변경 메뉴 | Task Catalog 그룹 미표시 |
| 게이트웨이 선택 → 변경 메뉴 | Task Catalog 그룹 미표시 |

## TC-2. 변경 메뉴로 적용 (타입 전환 포함)

| 단계 | 기대 결과 |
|---|---|
| 일반 작업 요소의 변경 메뉴에서 `결재 요청` 클릭 | 요소가 **사용자 작업** 모양으로 바뀌고 이름이 `결재 요청`으로 변경 |
| 요소 선택 → 속성패널 확인 | RACI·세부 절차·사용자 정의 속성 값이 카탈로그 등록값과 일치 |
| 섹션 제목 우측 | `결재 요청` 카탈로그 칩 표시 |
| 같은 요소에 `데이터 백업` 적용 | 서비스 작업으로 재전환, 이름 `데이터 백업` |

## TC-3. 기존 속성과의 병합 규칙

| 단계 | 기대 결과 |
|---|---|
| 새 Task에 패널에서 관련자료 링크 1건 입력 후 속성값 저장 | — |
| 그 요소에 `결재 요청` 적용 (카탈로그에 링크 없음 가정) | 기존 링크 유지 + 카탈로그의 RACI/절차 추가 |
| 카탈로그에 같은 키 값이 있는 경우 | 카탈로그 값으로 덮어써짐 |

## TC-4. 속성패널에서 불러오기/적용

| 단계 | 기대 결과 |
|---|---|
| Task 선택 → Task 카탈로그 섹션 펼침 | "카탈로그에서 불러오기" 검색 목록 + 적용 버튼 표시 |
| 목록 열기 | 항목이 이름 + (시스템 · 유형) 부제로 표시 |
| 항목 미선택 상태 | 적용 버튼 비활성 |
| `결재 요청` 선택 → 적용 | 타입/이름/속성 적용 + 패널 폼 즉시 갱신 + 성공 알림 |
| 패널에서 이름 수정(미저장) 후 다른 항목 적용 시도 | "저장되지 않은 내용…" 확인창, 취소하면 적용 안 됨 |
| 읽기 전용 모드 진입 | 불러오기/적용 UI 미표시, 적용된 카탈로그 이름만 표시 |

## TC-4b. 섹션 노출·순서 제어 (속성 스키마 스튜디오)

| 단계 | 기대 결과 |
|---|---|
| 관리자 콘솔 → 속성 스키마 관리 진입 | 목록에 'Task 카탈로그'(task 스코프, task_catalog) 행 존재 (스튜디오 첫 진입 시 자동 생성) |
| 스튜디오 미리보기(Task 대상) 확인 | 'Task 카탈로그' 섹션이 일반 다음 위치에 자리표시로 표시 |
| 행의 표시 순서를 큰 값(예: 200)으로 변경 | 패널에서 Task 카탈로그 섹션이 하단으로 이동 (미리보기도 동일) |
| 행 노출 해제 | 패널에서 Task 카탈로그 섹션 사라짐 · 변경(replace) 메뉴의 Task Catalog 그룹은 그대로 유지 (섹션만 제어) |
| 행 노출 복원 + 순서 원복(30) | 섹션이 일반 다음 위치로 복귀 |

## TC-5. 지속성

| 단계 | 기대 결과 |
|---|---|
| TC-2 적용 후 프로세스 저장 → 화면 재진입 | 요소 타입·이름·속성·카탈로그 칩 유지 |
| 적용 후 요소 속성 수정 → 저장 | 카탈로그 페이지의 원본 항목은 변경되지 않음 |

## TC-6. 회귀 확인

- [ ] 변경 메뉴의 기본 유형 목록(관리자 Task 종류 설정 필터링)이 이전과 동일하게 동작
- [ ] 카탈로그가 빈 테넌트에서 변경 메뉴에 Task Catalog 그룹이 나타나지 않고 기본 메뉴만 표시
- [ ] 비 PAL 테넌트: 변경 메뉴·속성패널 모두 카탈로그 UI 미노출 (customReplace 모듈은 PAL 전용 로드)
- [ ] 실행 모드/보기 모드에서 순서도 조회 시 오류 없이 렌더
