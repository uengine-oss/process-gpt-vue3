# 세션 2 · 선도 기업은 어떻게 AX 를 하고 있나 — 사례 카드

쏠리드 요청 B-1 "AX 전환에 앞서나가는 회사들은 어떻게 준비·실행하고 성과를 얻는가(CASE 1·2·3)"에 답하는 자료.
2026-10-08 공개 출처로 다시 확인했다. **독립 검증된 수치는 없다** — 모두 회사·벤더·정부(수혜 기업 집계) 발표이므로
발표 자료에는 "회사 발표 기준" 각주를 단다.

| 표기 | 뜻 |
|---|---|
| [회사] | 당사자·벤더 발표 |
| [정부] | 정부 보도자료(수혜 기업 자료를 정부가 집계) |
| [유엔진] | 유엔진 자체 사례 — 고객사명 외부 공개 범위 확인 전에는 익명으로 |

## CASE 2 — 재설계형

### 서연이화 · 4년 DX 위에 올린 제조 AI 에이전트
- **준비** 약 4년간 로우코드 플랫폼으로 설계·생산기술·품질·원가 업무를 디지털화하고 프로세스·데이터를 정비. 2026년을 "AX 원년"으로.
- **실행** 시험계획 자동 생성, 품질 개선대책서 작성 지원(연 약 2,000건 대상), 조립공정 설계안 제시, 설비 고장 원인·대책 추천 —
  모두 "에이전트가 초안, 현업이 검토·확정". 업무별 에이전트 20종, 약 8개월 사업(2026-08 착수 보도).
- **성과** 실증 단계 — **정량 성과는 아직 공개되지 않았다**(연 2,000건은 대상 규모).
- **쏠리드 시사점** 시험계획·품질대책서·설비보전 = 쏠리드의 시험·인증 문서, 품질 8D, 외주 제조 품질과 겹친다. "DX 로 데이터를 먼저,
  그 위에 에이전트" 순서의 근거.

### LG전자 · 에이전트 96개를 만들고 1년 뒤 46개가 남았다 (반면교사)
- **준비** 사내 AI 플랫폼 월 활성 약 3만 명.
- **실행** 지난해 에이전트 96개 개발, 현재 전사 125개 운영. 성과가 큰 것은 광고 문구 규제 검토·다국어 번역 — 번역은 임원이 부서 간 조율에
  직접 나서 성공.
- **성과** [회사·컨퍼런스 발표] 96개 중 **46개만 생존(약 50%)**. 실패 원인 "기술 중심 접근". 이후 에이전트 수 대신 에이전트별 생산성·비용
  절감을 대시보드로 측정.
- **쏠리드 시사점** CASE 1 을 많이 하는 것보다 현업 문제를 먼저 정의하라 — 국내 전자업계 근거.
