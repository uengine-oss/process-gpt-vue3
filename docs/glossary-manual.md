# 용어 정의 사전 매뉴얼

프로세스 규정서의 "용어 정의" 표(예: P5.4.3 내부심사 프로세스 7페이지의 [용어 | 정의] 표)를 시스템에서 관리하는 기능입니다.
두 곳에서 사용합니다:

1. **프로세스별 용어 정의** — 순서도 속성패널(Process 탭)의 "용어 정의" 섹션
2. **통합 용어 사전** — 사이드바 → 용어 사전 (`/glossary`)

PAL 모드 전용입니다.

## 프로세스에 용어 정의하기

1. 프로세스 체계도에서 프로세스를 열고 우측 속성패널의 **Process 탭**을 봅니다.
2. **용어 정의** 섹션을 펼칩니다 (기본 위치는 관련자료 링크 다음이며, 속성 스키마 스튜디오의
   '용어 정의' 행(process 스코프)으로 노출·순서·라벨을 바꿀 수 있습니다).
3. 용어 추가:
   - **용어** 입력란을 클릭하면 아래에 **기존 용어 추천 목록**이 나타납니다 —
     입력 전에는 등록된 용어 전체(최대 8개 표시, 초과분은 "외 N개"로 안내), 입력을 시작하면
     일치하는 용어만 정확도 순으로 좁혀집니다. 각 항목에는 정의 미리보기와 출처 프로세스명이 함께 표시됩니다.
   - 추천 항목을 클릭하면 **용어와 정의가 자동으로 채워집니다** (용어 재사용).
     어느 프로세스의 정의를 불러왔는지 입력란 아래에 표시됩니다.
     이미 이 프로세스에 등록된 용어는 목록에 "이 프로세스에 등록됨"으로 표시되고 선택할 수 없습니다.
   - **정의**를 입력(또는 불러온 정의를 수정)하고 **추가**를 클릭합니다.
     기존 용어와 똑같이 직접 타이핑한 경우, 정의를 비워 두고 추가하면 기존 정의가 자동으로 채워집니다.
4. 등록된 용어는 목록으로 표시되며 연필(수정)·휴지통(삭제) 아이콘으로 관리합니다.
   - 용어 옆 숫자 칩은 그 용어가 (다른 프로세스 포함) 몇 곳에서 정의되어 있는지를 나타냅니다.
   - 추가·수정·삭제는 프로세스 저장 버튼과 무관하게 **즉시 저장**됩니다.
   - 같은 프로세스 안에서 같은 용어는 중복 등록할 수 없습니다.

읽기 전용(보기) 모드에서는 목록만 표시되고 편집 UI는 나타나지 않습니다.

## 통합 용어 사전 보기

1. 좌측 사이드바 → **용어 사전** 클릭 (`/glossary`)
2. 테넌트의 모든 프로세스에서 정의한 용어가 **용어 단위로 묶여** 표시됩니다.
   - 용어 행을 펼치면 **어떤 프로세스에서 어떻게 정의해 쓰는지** 프로세스별 정의가 나열됩니다.
   - 프로세스명을 클릭하면 해당 프로세스의 체계도 화면으로 이동합니다.
   - 같은 용어 판정은 공백·대소문자를 무시합니다 (예: `FA(Focus Area)` = ` fa(focus area) `).
3. 상단 검색창으로 용어·정의·프로세스명을 검색할 수 있습니다.

## 저장되는 데이터

- 테이블: `glossary_terms` (테넌트 스코프, 조회는 구성원 전체·쓰기는 editor 이상)
- 행 단위 = (프로세스, 용어) 1건: `proc_def_id`(프로세스 식별자), `proc_def_name`(표시용, 저장 시 갱신),
  `term`, `definition`, `display_order`
- 같은 용어가 여러 프로세스에 정의될 수 있으며, 통합 사전과 재사용 자동완성이 이를 용어 단위로 묶어 사용합니다.
