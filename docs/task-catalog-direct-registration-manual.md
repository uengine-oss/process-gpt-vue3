# Task Catalog — 카탈로그 페이지 직접 등록 매뉴얼

자주 쓰는 Task(업무 단위)를 카탈로그에 미리 등록해 두고, 프로세스 순서도를 그릴 때 꺼내 쓰는 기능입니다.
이 문서는 **카탈로그 페이지에서 직접 Task를 등록·수정·삭제**하는 방법을 다룹니다.

> 프로세스 작성 중(속성패널)에 등록하는 방법은 `task-catalog-designer-registration-manual.md`,
> 등록된 Task를 순서도에서 사용하는 방법은 `task-catalog-usage-manual.md`를 참고하세요.

## 사전 조건

- PAL 모드 테넌트
- 관리자(admin) 권한 — 카탈로그 페이지는 관리자 콘솔 하위 메뉴입니다
- (선택) 속성 스키마: 관리자 콘솔 → 속성 스키마 스튜디오에서 Task 유형별 사용자 정의 속성을 정의해 두면
  등록 폼에 해당 필드가 자동으로 나타납니다

## 화면 진입

1. 좌측 사이드바 → 관리자 메뉴 → **카탈로그** (`/admin-console/task-catalog`)
2. 다른 관리자 콘솔 화면과 같은 표준 페이지 구조입니다:
   - 상단 헤더: **Task 카탈로그** 제목 + 설명 부제 + 우측 **Task 추가** 버튼
   - 그 아래 고정 툴바: 검색(이름·설명)과 Task 유형 필터
   - 카드 그리드 영역: 등록된 Task 목록 — 목록이 길면 이 영역만 스크롤됩니다 (헤더·툴바는 고정)

## Task 등록

1. 페이지 헤더 우측의 **Task 추가** 버튼 클릭
2. 등록 다이얼로그가 열립니다. 맨 위에서 **Task 유형**을 선택하면, 그 아래가
   **순서도 속성패널(Task 탭)과 같은 섹션 구성**으로 렌더링됩니다 —
   속성 스키마 스튜디오의 "속성패널 미리보기"와 같은 규칙(같은 섹션·순서·아이콘)이며,
   여기서는 값까지 직접 입력합니다. 유형을 바꾸면 표시되는 섹션·필드가 함께 바뀝니다.

   | 섹션 (접이식) | 설명 |
   |---|---|
   | 일반 | **이름(필수)**·설명(내장)과 무그룹 사용자 정의 필드가 표시 순서(display_order)로 통합 정렬됩니다 |
   | 사용자 정의 그룹 | 속성 스키마 스튜디오에서 정의한 묶음이 각각 별도 섹션으로 표시됩니다 |
   | RACI | 속성패널과 동일한 RACI 입력 위젯 (Task 계열 유형에만 표시) |
   | 세부 업무 수행 절차 | 속성패널과 동일한 절차 입력 위젯 (Task 계열 유형에만 표시) |
   | 관련자료 링크 | 이름 + URL 목록. 속성패널의 관련자료 링크와 같은 형식으로 저장됩니다 |
   | 그 외 패널 섹션 | 폼 연결·API 연동·입출력 데이터·FTE/OPEX·시스템 매핑·연관 과제·PI Flag 등 순서도 문맥이 필요한 섹션은 **"순서도에서 설정"** 자리표시로만 나타납니다 |

   섹션 순서는 속성 스키마 스튜디오에서 내장 속성의 표시 순서를 바꾸면 패널과 함께 이 다이얼로그에도 반영됩니다.

3. 필수 사용자 정의 속성이 비어 있으면 하단에 경고가 표시되고 저장 버튼이 잠깁니다.
4. **저장** 클릭 → 목록에 새 카드가 나타납니다.

### 참고: 내장 속성 노출 규칙

RACI / 세부 업무 수행 절차 / 관련자료 링크는 속성 스키마 스튜디오의 **노출 설정**을 따릅니다.
스튜디오에서 해당 내장 속성을 숨기면 등록 다이얼로그에서도 숨겨집니다 (속성패널과 동일 규칙).

## Task 수정 / 삭제

- 카드의 연필 아이콘 → 같은 다이얼로그에서 수정
- 카드의 휴지통 아이콘 → 삭제 확인 후 삭제
- 삭제해도 이미 순서도에 적용된 요소는 영향을 받지 않습니다 (적용 시점에 속성이 복사되기 때문)

## 저장되는 데이터

- 테이블: `task_catalog` (테넌트 스코프)
- `name` / `display_name` / `task_type` / `description` / `properties`(JSON)
- RACI(`raci`), 절차(`procedure`), 관련자료 링크(`manualLinks`), 사용자 정의 속성 값이 모두 `properties`에 담기며,
  순서도에 적용될 때 요소의 `uengine:Properties`로 그대로 복사됩니다 — 속성패널이 읽는 키와 동일합니다.

## 자주 묻는 질문

**Q. 등록 폼에 사용자 정의 속성이 안 보여요.**
속성 스키마 스튜디오에서 해당 필드의 적용 대상(applies_to)이 선택한 Task 유형(또는 `모든 Task`)인지,
활성/노출 상태인지 확인하세요. 다이얼로그는 열 때마다 전체 스키마를 다시 로드합니다.

**Q. Task 유형을 바꾸면 입력한 속성이 사라지나요?**
입력값은 유지되지만, 유형별 스키마가 다르면 화면에 표시되는 필드 집합이 달라집니다.
표시되지 않는 값도 `properties`에는 남아 있습니다.
