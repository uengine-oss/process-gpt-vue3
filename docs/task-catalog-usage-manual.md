# Task Catalog — 순서도에서 사용하기 매뉴얼

카탈로그에 등록된 Task를 프로세스 순서도에 적용하는 방법입니다.
별도 팔레트나 메뉴를 추가하지 않고, **기존 프로세스 작성 흐름 안에서** 두 가지 경로로 사용합니다:

1. **요소 변경(replace) 메뉴** — 캔버스에서 요소를 바꾸던 익숙한 방식 그대로
2. **속성패널의 Task 카탈로그 섹션** — 속성을 편집하던 자리에서 불러오기

> 등록 방법은 `task-catalog-direct-registration-manual.md`(카탈로그 페이지),
> `task-catalog-designer-registration-manual.md`(프로세스 작성 중)를 참고하세요.

## 사전 조건

- PAL 모드 테넌트, 프로세스 편집 권한
- 카탈로그에 등록된 Task가 1개 이상

## 방법 1 — 요소 변경(replace) 메뉴에서 적용

1. 순서도에 Task를 하나 배치합니다 (팔레트에서 일반 작업 등 아무 유형이나).
2. 요소를 클릭하고 컨텍스트 패드의 **스패너(변경) 아이콘**을 클릭합니다.
3. 변경 메뉴 하단에 **Task Catalog** 그룹이 나타납니다.
   - 등록된 Task가 유형 아이콘·이름·시스템(또는 설명)과 함께 나열됩니다.
   - 항목이 많으면 메뉴 상단 검색창에서 이름으로 필터링할 수 있습니다.
4. 원하는 항목을 클릭하면 한 번에 적용됩니다:
   - 요소의 **BPMN 타입**이 카탈로그의 Task 유형으로 바뀌고 (예: 일반 작업 → 사용자 작업)
   - **이름**이 카탈로그 Task 이름으로 바뀌며
   - **속성**(설명·RACI·세부 절차·관련자료 링크·사용자 정의 속성)이 요소에 병합됩니다.
     카탈로그에 없는 기존 속성 값은 유지되고, 겹치는 키는 카탈로그 값으로 덮어써집니다.

## 방법 2 — 속성패널에서 불러오기

1. Task 요소를 선택해 속성패널(Task 탭)을 엽니다.
2. **Task 카탈로그** 섹션을 펼칩니다 — 기본 위치는 일반 섹션 다음이고,
   속성 스키마 스튜디오의 'Task 카탈로그' 행으로 노출·순서를 조정할 수 있습니다.
3. **카탈로그에서 불러오기** 목록에서 항목을 검색·선택하고 **적용**을 클릭합니다.
   - 패널에 저장하지 않은 편집 내용이 있으면 덮어쓸지 확인을 요청합니다.
4. 적용 결과는 방법 1과 동일하며(공용 로직 사용), 적용 직후 패널 폼이 카탈로그 값으로 갱신됩니다.
5. 적용된 요소는 섹션 제목 오른쪽에 **적용된 카탈로그 항목 이름 칩**이 표시됩니다.

## 적용 대상 요소

Task 계열 전체와 Call Activity, Sub Process, Transaction에서 사용할 수 있습니다.
이벤트·게이트웨이·Lane·시퀀스 선에는 카탈로그 메뉴/섹션이 나타나지 않습니다.

## 적용 후 확인 포인트

- 속성패널을 열면 카탈로그에 등록해 둔 RACI·세부 절차·사용자 정의 속성이 그대로 보입니다.
- 적용은 다이어그램(메모리)과 저장소에 즉시 반영되며, 이후 일반 편집과 동일하게 수정할 수 있습니다.
- 적용 후 속성을 수정해도 카탈로그 원본에는 영향이 없습니다 (복사 방식).
  수정한 내용을 카탈로그에 반영하려면 "카탈로그에 저장"으로 다시 등록하거나 카탈로그 페이지에서 수정하세요.

## 관리자 설정과의 관계

- 변경 메뉴의 **기본 BPMN 유형 목록**은 관리자 콘솔의 Task/Event 종류 설정을 따릅니다.
  Task Catalog 그룹은 그 아래에 항상 추가로 표시됩니다 (카탈로그가 비어 있으면 표시되지 않음).
- 카탈로그 항목의 Task 유형이 관리자 설정에서 숨긴 유형이어도 적용은 가능합니다 —
  카탈로그 등록 시점에 유형이 확정된 것으로 간주합니다.
