# Task Catalog — 프로세스 작성 중 등록 테스트 가이드

대상 기능: 순서도 속성패널(Task 탭)의 "Task 카탈로그" 섹션 → 카탈로그에 저장
관련 매뉴얼: `task-catalog-designer-registration-manual.md`

## 준비

- [ ] PAL 모드 테넌트, 프로세스 편집 권한 계정으로 로그인
- [ ] 프로세스 체계도에서 편집 가능한 프로세스를 하나 열어 순서도 편집 화면 진입
- [ ] 테스트용 UserTask 요소 1개: 이름 `견적 검토`, 설명·RACI(R 조직 1개)·세부 절차 1단계 입력 후 속성값 저장

## TC-1. 섹션 노출 조건

| 단계 | 기대 결과 |
|---|---|
| UserTask 선택 | 속성패널 Task 탭에 "Task 카탈로그" 섹션 표시 — 기본 위치는 일반 섹션 다음, 기본 접힘 (위치·노출은 속성 스키마 스튜디오의 'Task 카탈로그' 행이 제어) |
| 시퀀스 선(화살표) 선택 | Task 카탈로그 섹션 미표시 |
| 게이트웨이/이벤트 선택 | Task 카탈로그 섹션 미표시 |
| Call Activity 선택 | Task 카탈로그 섹션 표시 |
| 읽기 전용(보기) 모드로 같은 요소 선택 | 등록 버튼·적용 UI 미표시 |

## TC-2. 프리필 등록

| 단계 | 기대 결과 |
|---|---|
| `견적 검토` 선택 → Task 카탈로그 섹션 펼침 → 카탈로그에 저장 클릭 | 등록 다이얼로그 열림, 제목 "Task 추가" |
| 프리필 확인 | 이름 `견적 검토`, 유형 `사용자 작업`, 설명·RACI·절차 값이 채워져 있음 |
| 저장 클릭 | 다이얼로그 닫힘 + "카탈로그에 등록되었습니다" 알림 |
| 섹션 제목 우측 확인 | 등록된 항목 이름 칩 표시 (카탈로그 참조 기록됨) |
| 카탈로그 페이지(`/admin-console/task-catalog`) 확인 | `견적 검토` 카드 존재, 수정으로 열면 RACI/절차 값 보존 |

## TC-3. 미저장 편집값 반영

| 단계 | 기대 결과 |
|---|---|
| 요소 선택 후 패널에서 이름을 `견적 검토 v2`로 수정 (속성값 저장 안 함) | — |
| 카탈로그에 저장 클릭 | 다이얼로그 이름 필드가 `견적 검토 v2` (패널에 보이는 값 기준) |
| 다이얼로그 닫고 패널 확인 | 패널 편집 상태 유지 (등록이 패널 폼을 초기화하지 않음) |

## TC-4. 등록 직후 사용 가능 여부

| 단계 | 기대 결과 |
|---|---|
| 같은 편집 세션에서 다른 Task 요소 선택 → Task 카탈로그 섹션 → 불러오기 목록 열기 | 방금 등록한 항목이 목록에 나타남 |
| 캔버스에서 다른 Task의 변경(스패너) 메뉴 열기 | Task Catalog 그룹에 방금 등록한 항목 표시 |

## TC-5. 반복 등록

| 단계 | 기대 결과 |
|---|---|
| 같은 요소로 카탈로그에 저장을 한 번 더 실행 후 저장 | 카탈로그에 동명 항목이 추가로 생성됨 (기존 항목 덮어쓰지 않음 — 의도된 동작) |

## TC-6. 회귀 확인

- [ ] 등록 후 프로세스 저장 → 재진입 시 요소 속성(이름/RACI/절차/사용자 정의)이 변형 없이 유지
- [ ] 비 PAL 테넌트에서는 속성패널에 Task 카탈로그 섹션이 나타나지 않음
