# Task Catalog — 프로세스 작성 중 등록 매뉴얼

순서도를 그리다가 "이 Task는 다른 프로세스에서도 계속 쓰겠다" 싶을 때,
**속성패널에서 바로 카탈로그에 등록**하는 기능입니다. 별도 화면으로 이동할 필요가 없습니다.

> 카탈로그 페이지에서 직접 등록하는 방법은 `task-catalog-direct-registration-manual.md`,
> 등록된 Task를 순서도에서 사용하는 방법은 `task-catalog-usage-manual.md`를 참고하세요.

## 사전 조건

- PAL 모드 테넌트
- 프로세스 편집 권한 (읽기 전용 모드에서는 등록 버튼이 표시되지 않습니다)

## 등록 방법

1. 프로세스 순서도 편집 화면에서 등록할 Task 요소를 클릭해 속성패널(Task 탭)을 엽니다.
2. **Task 카탈로그** 섹션을 펼칩니다 (기본은 접혀 있습니다).
   기본 위치는 일반 섹션 다음이며, 다른 패널 섹션처럼 **속성 스키마 스튜디오의 'Task 카탈로그' 행**(task 스코프)으로
   노출 여부와 표시 순서를 바꿀 수 있습니다.
3. **카탈로그에 저장** 버튼을 클릭합니다.
4. 등록 다이얼로그가 열립니다 — **카탈로그 페이지의 등록 다이얼로그와 동일한 화면**이며,
   현재 요소의 값이 미리 채워져 있습니다:
   - 이름·유형: 현재 요소의 이름과 BPMN 타입
   - 설명·RACI·세부 절차·관련자료 링크·사용자 정의 속성: 요소에 저장된 값
   - 속성패널에서 수정 중(아직 저장 전)인 값도 반영됩니다 — 화면에 보이는 값 그대로 등록됩니다
5. 필요한 값을 보완한 뒤 **저장**을 클릭합니다.
6. 등록이 끝나면:
   - "카탈로그에 등록되었습니다" 알림이 표시되고
   - 현재 요소에 카탈로그 참조가 기록되어, Task 카탈로그 섹션 제목 오른쪽에 등록된 항목 이름 칩이 표시됩니다.

## 카탈로그 적용 대상 요소

Task 계열 전체(일반/수동/서비스/사용자/스크립트/규칙/전송/수신 작업)와
Call Activity, Sub Process, Transaction에서 등록 버튼이 제공됩니다.
Lane·게이트웨이·이벤트·시퀀스 선에는 표시되지 않습니다.

## 동작 상세

- 등록 시 요소의 `uengine:Properties` 전체가 카탈로그 `properties`로 스냅샷됩니다.
  단, 요소 고유 상태(코멘트, 기존 카탈로그 참조)는 제외됩니다.
- 같은 이름으로 다시 등록하면 **새 항목이 추가**됩니다. 기존 항목을 갱신하려면
  카탈로그 페이지에서 해당 항목을 수정하세요.
- 등록 후 카탈로그 목록은 즉시 갱신되므로, 같은 편집 세션에서 바로
  변경(replace) 메뉴나 속성패널의 "카탈로그에서 불러오기"에 나타납니다.
