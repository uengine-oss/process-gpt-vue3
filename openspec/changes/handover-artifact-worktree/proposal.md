# Handover artifact worktree

## Why

대화창 인계는 고른 산출물을 **받는 방마다 복사**한다(`createChatHandover` 가 받는 방 작업 폴더
`files/skills/{tenant}/{받는 방}/` 에 새로 올린다). 병렬 인계가 생기면서 이 방식이 한계에 닿았다.

- 산출물 5개를 4명에게 나눠 주면 사본 20개, 그 4명이 다시 2명씩에게 넘기면 40개가 더 생긴다.
  이름이 겹치면 `(2)`, `(3)` 이 붙어 무엇이 원본이고 최신인지 알 수 없다.
- 두 갈래가 같은 파일을 각자 고치면 서로 다른 사본이 되고, 합류 지점에서 어느 쪽을 쓸지 알 수 없다.
- 사본이 받는 방에만 있어 **넘긴 사람은 받은 쪽이 고친 파일과 그 뒤에 만든 파일을 보지 못한다.**

git 자체가 아니라 **git 워크트리의 작업 모델**이 필요하다. 저장소는 하나, 작업 폴더는 여럿이고,
작업 폴더마다 자기 브랜치에서 일하며, 커밋은 바뀌지 않고, 어느 작업 폴더에서나 다른 브랜치의
이력을 본다. 인계 산출물을 이 모델로 관리하면 복사 없이 갈래를 나누고, 넘긴 사람도 결과를 본다.

## What Changes

- 업무 스레드(시작 방, `origin_room_id`)마다 **산출물 저장소** 하나를 둔다. 파일 내용은 해시로
  Storage 에 한 번만 저장하고, 커밋(스냅샷 = 경로 → 내용 해시)과 브랜치(방 → 최신 커밋)는 DB 에 둔다.
- **방 = 브랜치.** 방마다 자기 브랜치를 가지며 한 브랜치는 한 방에서만 쓴다.
- **인계 = 분기.** 넘기는 순간 넘기는 방의 작업 상태를 커밋하고, 그 커밋에서 받는 방 브랜치를 만든다.
  받는 방에는 파일을 복사하지 않는다. 병렬 인계는 같은 커밋에서 브랜치를 여러 개 만든다.
- **커밋 시점(자동).** 인계할 때, 받은 할 일을 완료할 때, 에이전트 실행 한 턴이 끝날 때 그 방의
  작업 상태를 커밋한다. 바뀐 것이 없으면 커밋하지 않는다.
- **커밋은 불변.** 고치면 새 커밋이다. 이전 상태는 그대로 남는다.
- **다른 브랜치 읽기.** 스레드에 참여한 누구나 다른 방 브랜치의 파일·변경 이력을 읽기 전용으로 본다.
  넘긴 사람은 갈래가 무엇을 고치고 새로 만들었는지 본다.
- **합류 = 병합.** 나눠 준 갈래가 끝난 뒤 다음 일을 넘기면, 갈래 브랜치들을 합친 스냅샷에서 받는
  방 브랜치를 만든다. 같은 경로가 갈래마다 다르면(충돌) 자동으로 고르지 않고 합류 지점 사람이 고른다.
- **에이전트 작업 폴더.** deepagents 는 실행을 시작할 때 그 방 브랜치의 최신 스냅샷을 작업 폴더로
  펼치고, 턴이 끝나면 바뀐 내용을 새 커밋으로 올린다. 지금의 방 폴더 내려받기를 대체한다.
- **화면.** 새 진입 버튼은 만들지 않는다. 기존 오른쪽 패널의 작업 흐름 그림 카드에 그 단계가 만든·
  고친 산출물을, '산출물 파일' 탭에 이 방 브랜치와 다른 브랜치의 산출물을 보인다.
- 이미 복사 방식으로 넘긴 인계 기록은 그대로 둔다. 새 인계부터 적용한다.
- git 프로그램·객체 형식·원격 저장소는 쓰지 않는다. 텍스트 줄 단위 자동 병합도 하지 않는다.

## Capabilities

### New Capabilities
- `handover-artifact-worktree`: 인계 스레드의 산출물을 저장소 하나 + 방별 브랜치로 관리한다.
  분기(인계·병렬 인계), 자동 커밋, 다른 브랜치 읽기, 합류 병합과 충돌 선택, 에이전트 작업 폴더 펼치기·올리기를 다룬다.

## Impact

- **DB(process-gpt-infra-docker, 로컬 supabase 마이그레이션)**: 스레드 산출물 저장소·커밋·브랜치·내용 객체
  테이블과 브랜치 갱신 함수(조건부 갱신으로 동시 갱신 안전).
- **Storage**: `files` 버킷에 내용 해시 키로 산출물을 저장(같은 내용은 한 번만).
- **process-gpt-vue3**: `createChatHandover`(복사 → 분기), 할 일 완료 시 커밋, 인계 창 산출물 후보(브랜치 파일),
  합류 충돌 선택, 산출물 패널·작업 흐름 그림의 산출물 표시.
- **process-gpt-deepagents**: 실행 시작 시 브랜치 스냅샷 펼치기, 턴 끝 커밋 올리기(지금의 방 폴더 하이드레이션·
  업로드 대체). 인계 할 일의 `[ChatRoom] <방 id>` 해석은 그대로 쓴다.
- **process-miner**: 영향 없음(인계 기록만 읽는다).
