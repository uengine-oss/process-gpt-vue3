## 3. 인계를 분기로 바꾸기 (process-gpt-vue3)

- [x] 3.1 `createChatHandover`: 넘기는 방 커밋(`handover`) → 고른 경로만 담은 tree 로 받는 방 브랜치 생성 → 인계 기록에 `base_commit_id`. 받는 방 작업 폴더에 파일을 올리지 않는다
- [x] 3.2 병렬 인계: 넘기는 방 커밋은 한 번, 받는 방 브랜치는 받는 사람 수만큼
- [x] 3.3 브랜치가 없는 넘기는 방(시작 방·예전 방)은 그 방 작업 폴더로 저장소·브랜치를 만든 뒤 분기
- [x] 3.4 인계 창 산출물 후보를 넘기는 방 브랜치 head 경로 목록으로(첨부·지식 문서는 고르면 객체로 올려 tree 에 넣음)
- [x] 3.5 받은 할 일 완료 시(할 일 목록 완료, `completeReceivedHandoverTask`) 그 방 작업 상태 커밋(`task_done`)
